# 世の中ちょっと良くするアプリ（Yoppy）

家族を支える小さな行動をミッションにして、アバターの元気度で応援を可視化するWebアプリです。

## 公開URL

GitHub Pagesで公開しています。

https://56448959qq-sudo.github.io/yoppy-1/

## 主な機能

- 起動時のローディング画面
  - `header_logo.png` と「世の中ちょっと良くする部」を表示
- 家族の設定
  - 応援したい家族の呼び名、アバター、年代・立場、性別を設定
  - 家族の属性に合ったミッションを表示し、女性には女性の健康に関するミッション、ミドル世代にはフレイル予防のミッションを用意
- 家族の元気度
  - ホーム画面にアバターと元気度（0〜100）を表示
  - ミッション達成で元気度が20回復し、オプショナルミッションでは5回復
  - ミッション未達成の日は翌日から1日ごとに10低下（0未満にはならない）
  - 元気度はアプリ内の応援表現で、実際の健康状態を示すものではありません
- 1日1ミッション
  - 毎日0:00に次のミッションへ更新
  - 次回更新までのカウントダウンを表示
- ミッション達成
  - 達成すると家族の元気度が回復
  - 紙吹雪のアニメーションを表示
- ストリーク
  - ミッションを連続達成した日数を表示
- オプショナルミッション
  - 1日のミッション達成後に追加ミッションを表示
  - 達成すると追加で元気度が回復
  - 同じ日に同じミッションを複数回達成できない仕組み
- 応援履歴
  - 最近達成したミッションと回復した元気度を表示
- タブナビゲーション
  - ホームと家族・記録を切り替えて表示
- ロゴの色と形を取り入れたUIデザイン

## ファイル構成

```text
.
├── index.html          # 公開用のエントリーポイント
├── code_artifact.html  # アプリ本体HTML
├── styles.css          # デザイン、レスポンシブ表示、アニメーション
├── script.js           # ミッション、タイマー、家族の元気度などの処理
└── header_logo.png     # アプリのロゴ
```

## ローカルでの実行

HTMLファイルを直接開くこともできますが、画像や外部ファイルを確実に読み込むため、ローカルサーバーの利用を推奨します。

```bash
python3 -m http.server 8000
```

ブラウザで以下を開きます。

```text
http://localhost:8000/
```

## データ保存について

家族の設定、元気度、達成履歴はブラウザの `localStorage` に保存されます。そのため、同じブラウザ・同じ端末では状態が維持されますが、別の端末やブラウザとは共有されません。
