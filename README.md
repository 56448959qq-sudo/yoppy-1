# 世の中ちょっと良くする部（Yoppy）

毎日の小さな行動をミッションにして、楽しみながら社会を少し良くしていくWebアプリです。

## 公開URL

GitHub Pagesで公開しています。

https://56448959qq-sudo.github.io/yoppy-1/

## 主な機能

- 起動時のローディング画面
  - `header_logo.png` と「世の中ちょっと良くする部」を表示
- プロフィール設定
  - 年代・立場、性別を設定
  - 属性に合ったミッションを表示
- 1日1ミッション
  - 毎日0:00に次のミッションへ更新
  - 次回更新までのカウントダウンを表示
- ミッション達成
  - 達成するとポイントを獲得
  - 紙吹雪のアニメーションを表示
- オプショナルミッション
  - 1日のミッション達成後に追加ミッションを表示
  - 達成すると追加ポイントを獲得
  - 同じ日に同じミッションを複数回達成できない仕組み
- ポイント履歴
  - 最近達成したミッションと獲得ポイントを表示
- みんなのランキング
  - 自分の順位、ポイント、他の参加者とのポイント差を表示
  - 現在はサンプル参加者によるデモ表示
- ロゴの色と形を取り入れたUIデザイン

## ファイル構成

```text
.
├── index.html          # 公開用のエントリーポイント
├── code_artifact.html  # アプリ本体HTML
├── styles.css          # デザイン、レスポンシブ表示、アニメーション
├── script.js           # ミッション、タイマー、ポイントなどの処理
└── header_logo.png     # アプリのロゴ
```

## ローカルでの実行

HTMLファイルを直接開くこともできますが、画像や外部ファイルを確実に読み込むため、ローカルサーバーの利用を推奨します。

```bash
python3 -m http.server 8000
```

ブラウザで以下を開きます。

```text
http://localhost:8000/
```

## データ保存について

ポイント、プロフィール、達成履歴はブラウザの `localStorage` に保存されます。そのため、同じブラウザ・同じ端末では状態が維持されますが、別の端末やブラウザとは共有されません。

ランキングも現在はこの仕組みに合わせたデモ表示です。複数ユーザー間で本当のポイント競争を行うには、認証機能とサーバーまたはデータベースの接続が必要です。
